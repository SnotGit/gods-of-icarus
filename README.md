# Gods Of Icarus

Builds your orbital inventory and your mounts in **Icarus**.
Runs on your own PC. Nothing is uploaded, no account.

## Install

1. [Download the zip](../../releases/latest)
2. Unzip it whole, anywhere.
3. Double-click `Gods Of Icarus.exe`

Your browser opens on the app. Close the tab and the program stops.

Windows will say *"Windows protected your PC"* — the file is not signed.
Click **More info**, then **Run anyway**.

## One rule

Write only from the character selection screen, or with the game closed.
A loaded character overwrites anything you write.

Your save is copied into `backups\` before every write.
